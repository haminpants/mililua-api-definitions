# Changelog

All notable changes to this project will be documented in this file.

## [3.5.0]

### Added
- Autocomplete Enum suggestions for functions with Enum parameters.

## [3.4.7]

### Changed
- Fixed Structure name extraction for structures with conflicting names, short names, or names containing special characters and whitespaces.

## [3.4.3]

## Added
- Add documentation to overloaded functions created for typed return values.

## [3.4.2]

## Added
- Read-only workspace settings to prevent accidental editing of the internal API definitions.

## [3.4.1]

### Added
- Word Completion is automatically disabled for new projects.
- Quick access buttons in the status bar hover menu to toggle Word Completions and the Need Nil Check lint.

## [3.4.0]

### Added
- Gil Resource Extraction for Structures.

### Changed
- Added type-checking for Custom Variables through `game.GetGlobalCustomVariableValue`.

## [3.3.0]

### Changed
- Added type-checking for Script Variables through `script:GetParam`.

## [3.2.0]

### Added
- Gil Resource Extraction for Custom Variable names.

## [3.1.0]

### Added
- Gil Resource Extraction for Script Variable names.

## [3.0.0]

### Changed
- Full extension rewrite.

## [2.4.0]
